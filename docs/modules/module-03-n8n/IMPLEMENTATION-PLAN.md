# 1. Purpose

This document defines the implementation plan for Module 3 – n8n Workflow Automation.

The objective is to transform the approved workflow architecture into a fully operational automation layer for ClientPilot.

---

# 2. Objectives

The implementation will:

- Connect Google Forms to Google Sheets.
- Process submissions in n8n.
- Create or update Company records.
- Create or update Contact records.
- Create Lead records.
- Prepare AI qualification.
- Notify the team.
- Prepare consultation scheduling.
