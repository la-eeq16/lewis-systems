# 1. Purpose

This module implements the ClientPilot client enquiry form using Google Forms.

The form acts as the primary client intake interface for the MVP, allowing prospective clients to submit their business information, contact details, and service requirements through a simple, professional, and mobile-friendly experience.

The information collected through the form serves as the starting point for the ClientPilot automation workflow.

---

# 2. Objectives

The Google Forms module is designed to:

- Capture prospective client enquiries.
- Collect company and contact information.
- Gather service requirements.
- Support lead qualification.
- Validate user input.
- Provide a consistent user experience.
- Supply structured data for downstream automation.

---

# 3. Deliverables

This module includes:

- Client Intake Google Form
- Five-section form structure
- Input validation
- Required field configuration
- Confirmation message
- CRM field mapping
- QA validation
- Module documentation

---

# 4. Form Structure

The Google Form consists of five logical sections:

1. Welcome
2. Company Information
3. Contact Information
4. Service Requirements
5. Review & Submit

The structure guides users through the enquiry process while keeping the form concise and easy to complete.

---

# 5. Integration Points

The Google Form is designed to integrate with:

- Google Forms
- Airtable CRM
- n8n
- OpenAI
- Slack
- Calendly

The submitted responses provide the input data required for the ClientPilot automation workflow.
