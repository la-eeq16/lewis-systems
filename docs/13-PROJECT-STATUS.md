# Development Methodology

Every implementation module follows the same lifecycle.

```
Design
   ↓
Build
   ↓
Test
   ↓
Document
   ↓
Git Commit
   ↓
Git Push
```

A module is only considered complete after all six stages have been successfully completed.

---

# Definition of Done

Every module must satisfy the following requirements before completion.

- ✅ Designed
- ✅ Built
- ✅ Tested
- ✅ Documented
- ✅ Committed to Git
- ✅ Pushed to GitHub
