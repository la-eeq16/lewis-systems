# Development Methodology

Every implementation module follows the Lewis Systems engineering lifecycle.

```text
Design
   ↓
Build
   ↓
Test
   ↓
Document
   ↓
Git Commit
   ↓
Git Push
```

A module is considered complete only after every stage has been successfully completed.
