# Make Workflow Exports

This directory is reserved for sanitised exports of the current ClientPilot Make scenarios.

Expected files:
- `WF-001A-CLIENT-INTAKE.blueprint.json`
- `WF-001B-LEAD-QUALIFICATION.blueprint.json`

**Current status:** Neither export has been supplied. This README is not a workflow export.

Before committing an export, remove credentials, tokens, private connection metadata, unnecessary account identifiers, and production customer data. Validate the JSON, record the scenario version and export date, and confirm it matches the live Make scenario.
